================================================================================
                              WHAT THIS PROJECT DOES
================================================================================

SafeFlock Solution is an end-to-end digital platform for the Indian poultry
industry. It connects poultry farmers, shop owners, healthcare product
providers, and delivery partners in one system.

CORE CAPABILITIES
-----------------
1. Product Catalog & E-Commerce
   - Browse verified poultry products: vaccines, medicines, feed supplements,
     water treatments, disinfectants.
   - Each product has a unique SKU, price, description, and QR token for
     traceability.
   - Live inventory qty is shown in real time.

2. Anti-Counterfeit QR Verification
   - Every product carries a unique QR token.
   - Users can scan or enter the token to verify authenticity.
   - System returns VERIFIED / ORIGINAL or FAKE / UNVERIFIED.

3. Role-Based Access Control (RBAC)
   - customer : buy products, manage cart, place orders, scan QR
   - provider : manage inventory, dispatch orders, assign logistics, print QR
   - logistics : view deliveries, update order status, verify delivery OTP

4. Cold-Chain IoT Monitoring
   - ESP32 sensors upload temperature and humidity readings.
   - Data is stored in MySQL and displayed on the IoT dashboard.
   - Alerts can be sent via SMS if readings go out of range.

5. Order & Delivery Management
   - Customers place orders from cart.
   - Providers dispatch orders and assign a logistics driver.
   - Logistics updates delivery status and verifies OTP at customer site.

6. OTP & Passkey Authentication
   - SMS OTP login via Textbee.
   - WebAuthn / passkey support for fingerprint / face login.
   - CSRF protection on all POST requests.

7. Utility Features
   - Dosage calculator for flock medicine dosing.
   - Returns & refunds management.
   - Dark / light theme with doodle UI.
   - PWA-ready (manifest.json, mobile-web-app-capable).

================================================================================
                              TECHNOLOGY & DESIGN PATTERNS
================================================================================

BACKEND
-------
- PHP 8+ with PDO for database access
- Session-based authentication with HttpOnly cookies
- CSRF tokens on all mutating requests
- Role-based route guards (sfs_require_role)
- Input sanitization and prepared statements (SQL injection prevention)
- Audit logging for sensitive actions

FRONTEND
--------
- Vanilla JavaScript (no framework dependency)
- Fetch API for AJAX calls to JSON endpoints
- CSS custom properties for theming (light/dark)
- Doodle / paper-cutout UI theme (Comic Neue, Gochi Hand fonts)
- Responsive grid layouts for product catalogs
- Mobile bottom dock navigation (role-aware)
- QR scanner integration

DATABASE
--------
- MySQL with InnoDB engine
- Foreign keys: products -> inventory, orders -> order_dispatch_items
- Indexed columns: sku, token, user_id, product_id
- Timestamps on all tables (created_at, updated_at)

SECURITY
--------
- CSRF protection (sfs_csrf_check)
- SQL injection prevention (PDO prepared statements)
- XSS prevention (htmlspecialchars on output)
- Session fixation protection (session_regenerate_id)
- HttpOnly + SameSite cookies
- OTP-based auth (Textbee SMS)
- WebAuthn passkey support
- Audit trail for QR scans and sensitive actions

================================================================================
                              KEY WORKFLOWS
================================================================================

1. CUSTOMER BUYS PRODUCT
   Browse products -> Add to cart -> Checkout -> Place order -> Provider sees order
   -> Provider dispatches -> Logistics delivers -> Delivery OTP verified

2. PROVIDER DISPATCHES ORDER
   Login as provider -> View orders in dashboard -> Assign driver -> Send OTP
   -> Logistics picks up -> Update status -> Deliver -> Customer receives OTP

3. QR VERIFICATION
   Scan QR code (or enter token) -> System checks qr_tokens table -> Returns
   product name, SKU, batch, IoT status -> Shows VERIFIED or FAKE badge

4. IoT MONITORING
   ESP32 sensor reads temp -> Publishes to MQTT (HiveMQ) -> Bridge server
   receives -> POSTs to iot_upload.php -> Stored in iot_readings table ->
   Displayed on IoT dashboard with status OK/WARNING/CRITICAL
